# 项目文档索引

已发布基线：v2.0.0，.NET 10 控制核心 + React/TypeScript 网页界面 + C# WebView2按需宿主；v1.0.0 托盘遮罩应用保留为兼容入口（不带 `--center` 启动）。Tailwind统一参数，shadcn/ui提供可维护组件，Motion负责短过渡，Lucide统一图标；不再采用WinUI或Tauri。

目标为个人使用优先的Windows显示器控制中心：双屏亮度、比例绑定、时间计划与渐变、场景切换、专注和登录自启。色温仅用硬件路径：直接写 DDC/CI 的 RGB 增益（VCP 0x16/0x18/0x1A），调色时把颜色预设（0x14）切到「用户」，恢复原色时切回原预设；DDC 命令失败会短暂重试。外屏RGB能力以实际每次探测结果为准，内屏只调亮度。当前仍处于开发验收期。
