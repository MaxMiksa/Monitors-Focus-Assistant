# 设计基础

目标是现代、直接、轻量的 Windows 控制面板。以 A 方案为基线，通过真实截图改进密度、可读性和状态表达。

唯一参数入口为 `src/MonitorsFocus.Web/src/index.css`，页面引用共享角色，不自行增加颜色、字号、圆角或动效数值。

| 规则 | 参数 |
| --- | --- |
| 字体 | 全部用户可见文字使用无衬线 Segoe UI Variable / Segoe UI / Microsoft YaHei UI，覆盖中文、英文、数字；系统字体回退仍为 sans-serif；不引入衬线字体或装饰字标 |
| 字号 | 仅 14 / 16 / 24 DIP，分别为辅助、正文/操作、标题/重点数值 |
| 字重 | 400 / 500 / 600，优先用字重与位置组织层级 |
| 空间 | 4 DIP 基础单位，常用 8 / 12 / 16 / 24 / 28；2 DIP 仅用于集中视觉校正 |
| 颜色 | 低饱和浅灰画布、白色操作面、深灰文本、蓝色主操作；状态同时用文字说明 |
| 控件 | 40 DIP 最小操作高度，保持键盘焦点和可访问名称 |
| 圆角 | 矩形控件与表面使用CSS corner-shape: superellipse(2)四次超椭圆连续曲率；控件曲线范围12，表面20；不用放大普通圆弧替代 |
| 基本几何 | 滑条轨道和圆形滑块保留其功能几何；操作系统窗口外框由系统绘制，不能伪称是自定义连续曲线 |
| 动效 | 操作反馈与局部切换150ms；不使用常驻装饰动画，尊重系统减少动态效果偏好 |

WebView2运行时需支持corner-shape；当前浏览器已实测支持，旧运行时需单独验收。背景、文字与控件始终在同一主题下渲染。默认浅色与确认图一致。任何系统控件未完成统一时列入待验收，不以“原生控件”为由跳过一致性检查。

字体档位数量通过代码检查，实际中文字形、控件内边距、连续曲线和DPI表现通过截图检查；不同 DPI 使用逻辑尺寸，不直接把窗口物理像素当逻辑像素。
