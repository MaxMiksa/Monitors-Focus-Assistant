# 使用体验

主要路径：打开托盘面板 → 调节两屏亮度 → 按需绑定比例或选择场景 → 回到工作。设置窗口负责时间计划、场景编辑、专注与自启。

当前真实设备为 AOC U27G4 外接屏与 BOE 笔记本内屏。色温只验证硬件路径（AOC 需切到「用户」颜色预设后增益才生效，2026-10-31 实测变暖与恢复原色正常），内屏显示“不支持硬件色温”，仍可调亮度。控制能力随实际检测变化，不能按品牌硬编码。

手动调整立即显示目标，硬件失败单独反馈；设备检测中禁用相关写入操作。保持比例要求两屏非零基准；归零后仍保留权重。场景保存正常亮度与色温、绑定开关及比例权重、专注开关和受控副屏规则，不保存临时专注遮罩状态。场景编辑沿用逐屏目标、表单开关和数值输入；“保存当前设置为新场景”捕获当前生效的正常目标与规则。受控范围默认全部副屏，也可逐个选择；全部关闭时不调暗任何屏幕，主屏始终保持亮度。离线副屏的选择按稳定标识保留。

手动切换场景立即应用上述目标和规则，时间计划在节点开始时应用绑定与专注规则，再按设定时长渐变亮度和色温。每次切换重新计算专注等待时间；计划持续渐变时不重复重置计时。专注等待时长、调暗亮度与临时暂停状态沿用全局设置。

自动调节共用时间轴，亮度与色温独立判断能力。到达节点后柔和缓入缓出，新增节点默认30分钟，可设数小时且须在下一节点前完成；跨午夜连续，图表遵循相同规则。手动调节与点击场景立即响应，覆盖保持到下个节点，可主动恢复计划。原色恢复停止当前色温干预。关闭界面释放 UI 进程，控制核心继续运行；退出应用先恢复临时调暗和颜色变换。

验收包含加载、可调、不可调、部分应用、保存失败、检测中和控制核心断开。错误不清空正在编辑的内容；状态刷新不抢焦点或重置输入。
