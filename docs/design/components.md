# 共享组件

| 组件 | 规则 |
| --- | --- |
| 文字 | 统一字体与14/16/24三档；数字列右对齐，数值变化不挤动标签 |
| 连续曲面 | CSS统一corner-shape与半径，矩形控件使用连续超椭圆角；圆形滑块保留功能几何 |
| 操作按钮 | shadcn Button统一主/次操作、悬停、焦点与禁用；Lucide提供功能图标 |
| 显示器调节行 | 名称、目标百分比、滑条、能力/错误；支持键盘方向键；故障时保留名称和重试入口 |
| 色温调节 | 单独标明作用屏幕，数值为近似色温；无能力时不允许操作 |
| 表单 | 同角色统一高度、内边距与连续轮廓；保存成功才刷新草稿，失败保留输入；设置页间保留草稿，Revision冲突需重新载入 |
| 时间计划 | 同一时间刻度展示目标变化；输入与曲线必须使用同一计算规则，不能使用装饰曲线 |

图形还原需检查整体布局、文字、交互状态与曲线轮廓；布局与功能分别验收。当前为实现过程，最终视觉与关键路径验收尚未完成。
